# Frontend Assessment — Bills Viewer

## Tech Stack

- React 19
- TypeScript
- Material UI
- TanStack Query
- Vite

## Getting Started

### Prerequisites

- Node.js v18+

### Installation

npm install

### Running in development mode

npm run dev

### Running tests

npm run test

### Linting

npm run lint

### Building for production

npm run build

## Features

- Browse and paginate legislation bills
- Filter bills by source and status
- Click a bill row to view English and Irish titles
- Favourite/unfavourite bills with persistent UI state
- View all favourited bills in a separate tab
